# Quickstart: App 页面结构与导航规划

## 目标

验证 HomeHoney 的页面结构与信息架构设计是否满足以下能力：

1. 首次使用者能完成欢迎引导并进入首页
2. 用户能从一级导航快速到达核心模块
3. 保险与说明书共享统一资料页面模式
4. 冰箱贴、备忘录、提醒与搜索形成完整协作闭环
5. 设置可承载主题、提醒和首页个性化能力

## 建议实施顺序

### 1. 欢迎与首页
- 实现欢迎页 / 引导页
- 实现首页摘要页
- 实现底部一级导航
- 为首页增加空状态与快捷操作

### 2. 资料模块
- 实现资料首页（保险 / 说明书入口）
- 实现保险列表页、详情页、新增页
- 实现说明书列表页、详情页、新增页
- 抽取共用文档卡片、筛选栏、详情区块组件

### 3. 家庭协作模块
- 实现家庭冰箱贴页
- 实现家庭备忘录列表与详情页
- 支持重要、待办、归档等状态

### 4. 横切能力
- 实现统一搜索页
- 实现提醒中心
- 接通首页摘要与目标详情页跳转

### 5. 设置与个性化
- 实现设置首页
- 实现主题切换
- 实现通知偏好
- 实现首页模块排序 / 可见性配置
- 实现隐私与安全入口

## 手动验收脚本

### 场景 A：首次使用路径
1. 启动应用
2. 确认显示欢迎与引导页
3. 完成引导进入首页
4. 确认首页能看到至少以下入口：资料、冰箱贴、提醒、设置

### 场景 B：资料管理路径
1. 从首页或底部导航进入资料模块
2. 分别进入保险与说明书分组
3. 验证每个分组存在列表、详情、新增入口
4. 验证筛选与搜索入口在页面上有明确位置

### 场景 C：家庭协作路径
1. 进入冰箱贴页面
2. 验证页面适合快速记录短内容
3. 进入备忘录页面
4. 验证页面适合浏览较长、可归档的正式记录

### 场景 D：跨模块查找路径
1. 进入首页摘要或搜索页
2. 搜索一条保险、说明书或备忘内容
3. 验证结果按类型分组，并能跳转到对应详情页
4. 进入提醒中心，验证可见跨模块待处理事项

### 场景 E：设置路径
1. 进入设置页面
2. 切换浅色 / 深色 / 跟随系统主题
3. 调整某一类提醒开关
4. 调整首页某个模块的可见性或顺序
5. 验证设置影响能反映到首页或相关页面

## 页面结构建议总览

```text
欢迎与引导
└── 欢迎页
    ├── 功能介绍页
    └── 进入首页

一级导航
├── 首页
├── 资料
│   ├── 保险
│   │   ├── 列表
│   │   ├── 详情
│   │   └── 新增/编辑
│   └── 说明书
│       ├── 列表
│       ├── 详情
│       └── 新增/编辑
├── 冰箱贴
├── 提醒
│   └── 搜索（可作为提醒页顶部入口或全局入口）
└── 设置
```

## 完成定义

当以下条件全部满足时，可视为本设计落地成功：

- 一级导航与页面职责清晰
- 所有核心模块均有明确入口与返回路径
- 页面结构支持后续组件化实现
- 用户首次进入、长期使用和临时查找三类场景都被覆盖
