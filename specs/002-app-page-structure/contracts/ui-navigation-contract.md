# UI Navigation Contract

## 1. 一级导航契约

| 导航项 | 默认入口路由 | 主要职责 | 关键子页面 |
|--------|--------------|----------|------------|
| 首页 | `/` | 跨模块摘要、快捷入口、最近事项、空状态引导 | 欢迎后首页、最近资料、即将到期、快捷操作 |
| 资料 | `/documents` | 家庭资料聚合入口 | 保险列表、保险详情、保险新增、说明书列表、说明书详情、说明书新增 |
| 冰箱贴 | `/fridge-notes` | 快速记录短便签、留言、购物和待办 | 便签墙、快速新增、筛选 |
| 提醒 | `/reminders` | 聚合待处理事项、搜索、快速定位 | 提醒中心、搜索结果、即将到期列表 |
| 设置 | `/settings` | 外观、提醒、首页布局、隐私与帮助 | 主题设置、通知设置、首页布局、隐私与安全 |

## 3. 页面行为契约

### 首页
- 必须展示至少一个“下一步行动”入口
- 必须可直达资料、冰箱贴、提醒、设置
- 若无数据，必须展示空状态与推荐操作

### 资料列表页
- 必须提供搜索、筛选、排序和新增入口
- 必须可进入详情页
- 空状态下必须可一键进入新增页

### 详情页
- 必须展示关键字段摘要
- 必须提供返回列表与编辑入口
- 若存在提醒或附件，应有明确展示区块

### 冰箱贴页
- 必须支持快速新增
- 必须通过视觉样式区分优先级或状态

### 提醒中心
- 必须按时间或优先级聚合多来源事项
- 必须支持点击后跳转至源详情页

### 设置页
- 必须即时反馈主题切换
- 必须分区承载外观、提醒、首页布局、隐私与安全

## 4. 导航规则

- 一级导航在所有核心页面中保持稳定可见
- 从搜索结果和提醒中心进入详情页后，用户必须能清楚返回来源页或对应模块
- 新增/编辑页完成后应回到所属模块上下文，而不是直接丢回首页
- 欢迎引导仅首次完整展示，后续通过设置或帮助入口重新访问
