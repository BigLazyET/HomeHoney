# UI Behavior Contract

## 1. 删除行为契约

### 1.1 资料模块

| 页面 | 删除对象 | 删除入口 | 确认要求 | 删除成功后跳转 |
|------|----------|----------|----------|----------------|
| `/documents/insurance/:id` | 保险记录 | 详情页动作区 | 必须确认 | `/documents/insurance` |
| `/documents/insurance/:id/edit` | 保险记录 | 编辑页动作区 | 必须确认 | `/documents/insurance` |
| `/documents/manuals/:id` | 说明书记录 | 详情页动作区 | 必须确认 | `/documents/manuals` |
| `/documents/manuals/:id/edit` | 说明书记录 | 编辑页动作区 | 必须确认 | `/documents/manuals` |

### 1.2 冰箱贴模块

| 页面 | 删除对象 | 删除入口 | 确认要求 | 删除成功后跳转 |
|------|----------|----------|----------|----------------|
| `/fridge-notes/:id/edit` | 冰箱贴 | 编辑页动作区 | 必须确认 | `/fridge-notes` |

### 1.3 删除一致性规则

- 删除前必须展示明确确认步骤
- 未确认前不得修改数据
- 删除成功后，已删除内容不得继续出现在：
  - 所属模块列表
  - 首页摘要
  - 搜索结果
  - 提醒聚合结果
- 删除后的原详情页路由若再次访问，必须展示“未找到”或空状态，而非旧数据

## 2. 返回导航契约

### 2.1 返回按钮展示规则

| 页面层级 | 是否显示返回按钮 | 说明 |
|----------|------------------|------|
| 一级入口页 | 否 | 如首页、资料首页、冰箱贴首页、提醒首页、设置首页 |
| 二级页面 | 是 | 如保险列表、说明书列表、设置子页面 |
| 三级页面及更深页面 | 是 | 如详情页、编辑页 |

### 2.2 返回目标规则

| 当前页面 | 默认返回目标 |
|----------|--------------|
| 保险列表 | `/documents` |
| 保险详情 | `/documents/insurance` |
| 保险编辑 | `/documents/insurance/:id` 或 `/documents/insurance` |
| 说明书列表 | `/documents` |
| 说明书详情 | `/documents/manuals` |
| 说明书编辑 | `/documents/manuals/:id` 或 `/documents/manuals` |
| 冰箱贴编辑 | `/fridge-notes` |
| 设置子页 | `/settings` |
| 欢迎子页 | `/welcome` 或上一步引导页 |

### 2.3 返回一致性规则

- 返回行为应优先遵循业务层级，而非仅依赖浏览历史
- 搜索结果进入详情页后，返回按钮至少要能回到对应模块列表
- 删除操作后的跳转视为一种特殊“返回”，目标必须是仍然有效的上一级页面

## 3. 首次引导契约

### 3.1 自动展示规则

| 条件 | 启动行为 |
|------|----------|
| `OnboardingCompleted = false` | 自动进入引导流程 |
| `OnboardingCompleted = true` | 直接进入主页面 |

### 3.2 状态变更规则

- 用户在首次引导中点击完成后，系统必须把 `OnboardingCompleted` 记录为已完成
- 用户未完成首次引导直接退出应用时，系统不得把引导误记为已完成
- 用户通过设置或帮助主动查看引导时，不得自动重置首次启动逻辑

### 3.3 重新访问规则

- 可通过设置或帮助入口再次进入引导内容
- 当前实现通过设置中的主动入口跳转到 `/welcome?mode=preview`
- 再次进入属于主动查看行为，不等同于“恢复首次启动状态”
- 主动查看结束后，下次启动仍应直接进入主页面
