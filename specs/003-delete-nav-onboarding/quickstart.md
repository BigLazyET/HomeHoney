# Quickstart: 资料删除、返回导航与首次引导优化

## 目标

验证 HomeHoney 在当前页面结构基础上补齐以下能力：

1. 资料与冰箱贴支持安全删除
2. 多层页面具有稳定返回路径
3. 引导仅在首次自动出现，后续启动直接进入主页面

## 建议实施顺序

### 1. 删除闭环
- 为 `DocumentCatalogService` 增加保险与说明书删除方法
- 为 `FamilyCollaborationService` 增加冰箱贴删除方法
- 在资料详情页、资料编辑页和冰箱贴编辑页接入删除入口与确认交互
- 确保删除后列表、首页摘要和搜索/提醒聚合即时同步

### 2. 返回导航
- 统一梳理一级、二级、三级页面层级
- 在二级及更深页面加入返回按钮
- 让返回目标遵循业务层级而非仅依赖历史栈
- 对设置子页、资料详情页、编辑页分别验证返回路径

### 3. 首次引导规则
- 保持首次未完成引导时的默认引导入口
- 完成引导后持久化完成状态
- 再次打开应用时直接进入主页面
- 保留帮助/设置中的主动回看入口（当前通过 `/welcome?mode=preview` 进入），但不重置默认启动逻辑

## 手动验收脚本

### 场景 A：删除资料
1. 进入保险列表并打开一条保险详情
2. 点击删除并完成确认
3. 验证页面跳回保险列表
4. 验证已删除内容不再出现在保险列表与首页摘要中
5. 对说明书重复一次同样流程

### 场景 B：删除冰箱贴
1. 进入冰箱贴页面并选择一条已有冰箱贴进行编辑
2. 点击删除并完成确认
3. 验证页面跳回冰箱贴主页面
4. 验证已删除冰箱贴不再出现在冰箱贴板与首页摘要中

### 场景 C：多层页面返回
1. 从资料首页进入保险列表
2. 在保险列表点击返回，验证回到资料首页
3. 再进入保险详情，点击返回，验证回到保险列表
4. 进入保险编辑页，点击返回，验证回到详情页或保险列表
5. 对设置子页执行同样验证，确认返回至设置首页

### 场景 D：首次引导与后续启动
1. 清除本地偏好状态或使用首次安装环境启动应用
2. 验证应用自动进入欢迎引导
3. 完成引导并进入主页面
4. 关闭应用后再次启动
5. 验证应用直接进入主页面，而不是再次自动进入引导

### 场景 E：主动回看引导
1. 在已完成首次引导的状态下，从设置或帮助入口重新进入引导
2. 浏览后退出引导内容
3. 关闭并重新打开应用
4. 验证应用仍直接进入主页面

## 完成定义

当以下条件全部满足时，本特性视为设计落地成功：

- 保险、说明书和冰箱贴都能完成“删除确认 → 删除成功 → 返回有效列表页”的完整闭环
- 所有二级及更深页面都具备清晰的返回入口
- 已完成首次引导的用户后续启动不再被自动带回引导页
- 主动回看引导不会破坏默认启动行为
