# Upgrade Validation Contract

## 1. 目标

定义 HomeHoney 升级到 .NET 10 后必须满足的验证契约，确保团队能用统一入口判断升级是否真正完成。

## 2. 输入契约

### 2.1 环境前提

| 项目 | 要求 |
|------|------|
| SDK | 已安装 .NET 10 SDK（仓库默认锁定到 10.0.102） |
| 工作负载 | MAUI 所需工作负载与 SDK 对应 |
| 仓库状态 | 使用升级分支代码 |
| 平台工具 | 保持现有 iOS / Android / Mac Catalyst / Windows 条件构建前提；当前验证要求 Xcode 26.2 与 Java 17+ |

### 2.2 仓库前提

| 项目 | 要求 |
|------|------|
| `global.json` | 指向 .NET 10 基线 |
| 主应用项目 | 使用 `net10.0` / `net10.0-*` 目标框架族 |
| 测试项目 | 使用 `net10.0` |
| 文档 | README 与 quickstart 已同步升级说明 |

## 3. 验证流程契约

### 3.1 CLI 验证链路

| 顺序 | 操作 | 期望结果 | 阻塞性 |
|------|------|----------|--------|
| 1 | 检查 SDK 可用性 | 当前环境可识别 .NET 10 SDK | 是 |
| 2 | 执行 `dotnet workload restore` | 不出现 MAUI 工作负载与 SDK 版本不匹配导致的恢复失败 | 是 |
| 3 | 构建 `HomeHoney.sln` | 主应用与测试工程构建通过 | 是 |
| 4 | 运行 `HomeHoney.Tests` | 所有测试通过 | 是 |
| 5 | 抽样检查核心入口 | 首页、欢迎流、资料、冰箱贴、提醒、设置可进入 | 是 |

### 3.2 失败分类

| 失败类型 | 判断标准 | 处理方向 |
|----------|----------|----------|
| 环境失败 | SDK、工作负载、Xcode 或 Java 版本不匹配 | 修正本地或 CI 环境前提 |
| 构建失败 | 项目文件、平台配置或依赖不兼容 | 修正工程配置或兼容性问题 |
| 测试失败 | 现有单元/组件测试回归失败 | 修正升级引入的行为差异 |
| 功能回归 | 核心入口可编译但不可用 | 修正运行时或页面兼容问题 |
| 文档失配 | 文档与实际验证方式不一致 | 同步 README / 规范说明 |

## 4. 输出契约

升级完成时，必须同时满足以下输出结果：

1. 解决方案构建通过
2. 测试项目通过
3. 目标平台范围未出现未声明缩减
4. 仓库文档能够独立指导团队完成环境准备与验证
5. 关键回归结果可被记录到 tasks / quickstart / README 中

## 5. 非目标说明

以下内容不属于本次升级契约的必选输出：

- 新增业务功能
- 大规模页面重构
- 存储架构迁移
- 与 .NET 10 升级无关的 UI 设计调整
