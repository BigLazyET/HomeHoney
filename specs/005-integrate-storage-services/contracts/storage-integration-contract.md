# Storage Integration Contract

## 1. 目标

定义 HomeHoney 在接入外部文件服务与 MongoDB 后必须满足的用户可见契约、数据边界契约与一致性契约。

## 2. 配置契约

### 2.1 用户可编辑配置

| 项目 | 要求 |
|------|------|
| 文件服务地址 | 用户可查看、修改、保存，并在重启后继续生效 |
| 数据服务地址/连接信息 | 用户可查看、修改、保存，并在重启后继续生效 |
| 敏感凭据 | 不得以明文普通偏好形式暴露给 UI 之外的日志或错误输出 |
| 配置校验 | 保存前必须阻止明显无效的 URI 或缺失字段 |
| 激活规则 | 任一时间只能存在一个当前生效的配置档 |

### 2.2 配置失败反馈

| 场景 | 最低反馈要求 |
|------|--------------|
| 地址格式无效 | 明确指出输入不可保存 |
| 服务不可达 | 提示连接失败，并允许继续修改 |
| 凭据无效 | 提示认证失败，不得误报为“无数据” |

## 3. 文件资源契约

### 3.1 职责边界

| 数据类型 | 存储位置 |
|----------|----------|
| 保险合同、说明书等文件本体 | 外部文件服务 |
| 文件标题、标签、分类、成员归属、更新时间、文件引用 | MongoDB |

### 3.2 文件操作语义

| 操作 | 输入 | 输出 | 通过标准 |
|------|------|------|----------|
| 列表 | 文档分类 / 查询条件 | 业务元数据列表 + 文件可用状态 | 用户能看到正确的文件性质资源列表 |
| 详情 | `DocumentId` | 结构化元数据 + 文件引用状态 | 用户能识别文件是否可访问 |
| 上传 | 文件流 + 元数据草稿 | 新文件引用 + 已保存业务记录 | 文件本体与元数据最终都可追踪 |
| 下载 | `DocumentId` 或 `FileResourceId` | 文件流 / 本地缓存文件 | 用户可打开或保存原文件 |
| 删除 | `DocumentId` | 记录删除结果 + 一致性状态 | 列表中不再展示已删除业务记录 |

### 3.3 异常状态

| 状态 | 定义 | UI 要求 |
|------|------|---------|
| `Healthy` | 元数据和文件本体都可访问 | 正常展示 |
| `PendingUpload` | 草稿已建，文件尚未完成上传 | 提示待完成 |
| `FileMissing` | 元数据存在但远端文件不存在 | 明确显示文件缺失 |
| `SyncError` | 跨服务写入部分失败 | 提示可重试或待修复 |

## 4. 非文件数据契约

### 4.1 范围

以下数据必须存入 MongoDB，并支持标准 CRUD：

- 冰箱贴
- 家庭备忘录
- 提醒项
- 用户偏好
- 家庭成员
- 空间信息
- 文件性质资源的结构化元数据

### 4.2 CRUD 语义

| 操作 | 契约要求 |
|------|----------|
| Create | 返回新记录标识，并可在后续查询中读取到 |
| Read | 页面刷新或重启后能读取最新远端或缓存后的有效结果 |
| Update | 修改结果应覆盖旧值，并更新最后更新时间 |
| Delete | 删除后不能在正常列表中继续显示 |

## 5. 离线与缓存契约

| 项目 | 要求 |
|------|------|
| 文档元数据缓存 | 必须保留最近同步成功的数据快照 |
| 已下载文件缓存 | 必须允许用户在离线时访问已缓存文件 |
| 服务失败提示 | 不得把连接失败显示成“空列表” |
| 同步状态 | 必须能区分本地缓存视图和远端最新状态 |

## 6. 测试与验收契约

| 验证主题 | 最低要求 |
|----------|----------|
| 配置持久化 | 修改配置后重启仍生效 |
| 文件读写 | 列表、上传、下载、缺失文件提示均可验证 |
| Mongo CRUD | 至少一类非文件业务数据完成增删查改回归 |
| 跨服务一致性 | 能识别并展示部分成功/部分失败 |
| 离线回退 | 服务不可达时仍能读取缓存并展示明确状态 |
